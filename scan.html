What I test

  • Retry after ambiguous outcome: did the effect succeed before the response was lost?
  • Concurrent duplicate intent: can two requests representing one logical action both pass?
  • Replay identity: does the same action retain the same logical identity across retries?
  • Budget / policy races: can concurrent requests consume the same remaining allowance?
  • Boundary placement: is enforcement authoritative before the irreversible effect?

What you receive

  • 1. Reproduction fixture when feasible, or a bounded inconclusive / no-finding result.
  • 2. Documented execution boundary and observed behavior.
  • 3. Available test evidence and observed duplicate-effect / budget behavior.
  • 4. Claim limits: what the test proves and what it does not.
  • 5. Focused recommendations and suggested verification steps, where applicable.

Designed for consequential agent paths

Best fit: AI agents that can trigger payments, wallet transfers, paid APIs, purchases, refunds, orders, trades, or other externally visible side effects where a retry or duplicate execution has economic cost.
