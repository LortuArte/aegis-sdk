What I test

  • Retry after ambiguous outcome: did the effect succeed before the response was lost?
  • Concurrent duplicate intent: can two requests representing one logical action both pass?
  • Replay identity: does the same action retain the same logical identity across retries?
  • Budget / policy races: can concurrent requests consume the same remaining allowance?
  • Boundary placement: is enforcement authoritative before the irreversible effect?

What you receive

  • 1. Reproduction fixture or clean bounded verdict.
  • 2. Exact affected execution boundary.
  • 3. Raw evidence and observed duplicate-effect / budget behavior.
  • 4. Claim limits: what the test proves and what it does not.
  • 5. Focused remediation recommendation and verification test.
